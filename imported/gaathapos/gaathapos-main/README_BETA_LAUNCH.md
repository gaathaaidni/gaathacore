## Deployment checks (automation)

We provide simple automation to validate a deployed site before release:

- `tests/test_deployed_site.py` — runs quick smoke checks against `DEPLOY_URL` (set env var)
- `scripts/link_check.py` — lightweight crawler that reports broken links (run with `DEPLOY_URL`)

Usage examples:

```
DEPLOY_URL=https://your-app.pythonanywhere.com \
  SUPERADMIN_USER=superadmin SUPERADMIN_PASS=superadmin@123 \
  pytest tests/test_deployed_site.py -q

DEPLOY_URL=https://your-app.pythonanywhere.com python scripts/link_check.py
```

Run these against a staging instance first and make sure you have test accounts available. If you want, I can extend these checks to include:

- End-to-end UI flows (Playwright) for login, signup, POS flows and checkout
- Accessibility checks (axe)
- Security scans (bandit/safety/OWASP checks)
