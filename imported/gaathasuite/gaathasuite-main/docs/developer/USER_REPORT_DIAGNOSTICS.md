# User Report Diagnostics

**Status:** IMPLEMENTED support template.

Capture only what is necessary:

```text
Customer:
Organization:
Affected role:
Module/page:
Action:
Expected result:
Actual result:
Timestamp and timezone:
Visible error:
Reproduction steps:
Browser/device:
Request/API if known:
Severity:
```

Never request passwords, authentication tokens, payment-card information, or unnecessary personal data. Use P0 for critical outage/security incident, P1 for major business function unavailable, P2 for degraded important functionality, and P3 for minor issue/question. These are internal suggested severities, not SLA commitments.
