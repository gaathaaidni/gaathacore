# Responsible Disclosure

**Status:** FOUNDATION ONLY / CONTACT NOT CONFIGURED.

Report suspected security issues privately through:

```text
SECURITY_CONTACT_EMAIL: [TO BE CONFIGURED]
```

Include impact, affected route/module, reproduction steps, timestamps, and sanitized evidence. Do not include passwords, tokens, secrets, or payment-card data. Do not publish a vulnerability before the operator has had a reasonable opportunity to investigate.
