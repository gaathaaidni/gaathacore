# Getting Started

**Status:** PARTIALLY IMPLEMENTED / UI workflow NOT YET VERIFIED.

1. Obtain an account through the deployed authentication flow.
2. Sign in with the available login route.
3. Confirm that the account has an organization association.
4. Ask an organization administrator to create or invite users through the available user-management route.
5. Use the dashboard and registered modules available to your role.

JWT authentication, inactive-account rejection, and organization-aware dashboard behavior are implemented. Password recovery, email verification, and a complete guided onboarding journey are not verified as production workflows. Do not share passwords or tokens with support.
